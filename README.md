A make.fun bounty entry. The program writes one satirical sentence —
a roast of lawmakers who would regulate AI, crypto or the internet but
cannot convert a file to PDF — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

`OUTPUT_PATH` overrides the output location (default `/output/entry.txt`).

## Entry

> The lawmakers who spent six months writing 214 pages of rules for
> artificial intelligence still print their own bill, sign it in pen,
> and hand it to an intern to scan it back into a PDF.

One sentence, 186 characters — inside the 1–320 character gate.
